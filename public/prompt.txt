Design a clean, modern, mobile-first app UI for a rental listing platform focused on IT employees in Navi Mumbai.

App concept:
A very simple platform where flat owners can post a single listing (1 image only), and users can browse rooms/flats by area for rent or daily stay. No complex features like chat, payments, or reviews.

Target audience:
Young IT professionals working in Navi Mumbai looking for quick rental options or short stays.

Design style:

* Minimal, fast, and clutter-free
* Inspired by Airbnb but much simpler
* Use soft colors, clean typography, rounded cards
* Focus on usability and speed

Screens to design:

1. Home Screen

* Header with app name and location selector
* Area filter chips (Vashi, Airoli, Thane, Nerul, etc.)
* Listing cards (image, price, type: rent/daily, area)
* Sticky bottom navigation (Home, Post Listing, Profile)

2. Listing Detail Screen

* Large image at top (single image only)
* Price, type (rent/daily stay), area
* Short description
* "Call Owner" button (primary CTA)
* If user not logged in, show login prompt on CTA click

3. Create Listing Screen (Owner)

* Simple form:

  * Upload 1 image
  * Title
  * Price
  * Select area (dropdown with fixed options)
  * Type (Rent / Daily Stay toggle)
  * Description
* Submit button
* Show note: "Only one active listing allowed per user"

4. Login Screen

* Phone number input (OTP-based login)
* Minimal UI

5. Profile Screen

* Show user's listing (if exists)
* Option to delete listing

UX constraints:

* Keep everything extremely simple and fast
* Avoid heavy filters, maps, or complex flows
* Optimize for one-hand mobile usage
* Prioritize quick browsing and quick contact

Components:

* Reusable listing cards
* Filter chips
* Primary CTA button
* Bottom navigation bar

Goal:
Design an MVP that can be built quickly and converted into a mobile app using Capacitor, focusing on speed and simplicity rather than feature richness.
